# Internationalization

> Language contract for agents working on copy/layout. Inspect `lib/i18n` for the actual message/context implementation before adding keys.

## Current locales

Supported user-facing locales are:

```text
en
bn
```

The app uses a hand-rolled i18n context/messages implementation rather than next-intl.

Do not introduce locale routes or another i18n library just to add a string.

## Translation rules

Translate:

- navigation labels
- screen headings
- buttons/actions
- empty/error states
- toasts
- settings/account/sync/share copy
- accessibility labels

Do not machine-translate user-entered content such as notebook names, person names or notes.

The product name `Khata` remains `Khata`.

## Product vocabulary

Preferred Bengali transaction language:

```text
দিলাম
নিলাম
```

Do not introduce:

```text
পাবো
দেবো
owed/debt/payable/receivable
```

The app is not a debt-management product.

## Numbers and money

Amounts are stored as integer paise internally.

Presentation uses the shared money formatter. Do not concatenate currency symbols/labels ad hoc inside components.

The current interface uses Latin digits for money/date presentation unless the shared formatter is intentionally changed as part of a separate localization decision.

## Layout requirements

Every changed screen must remain usable in both English and Bengali.

Never assume English-length strings for button widths, tab labels, menus or error messages.

Keep labels short when the product meaning permits it rather than shrinking the font to fit.

## Agent workflow

When adding/changing a message:

1. Find the existing namespace/key pattern.
2. Add the English and Bengali entries together.
3. Search call sites to ensure the same semantic label is not duplicated elsewhere.
4. Preserve the existing copy vocabulary.
5. Check that accessibility labels also receive the right locale string where appropriate.

Native Bengali review remains a human quality gate for nuanced copy. A coding agent can validate key coverage and usage, but cannot certify natural native-speaker phrasing.
